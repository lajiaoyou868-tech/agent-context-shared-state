# 给全新聊天的盲测提示词

只提供本文件内容和只读 MCP 连接。不要把 demo 输出、评分表、正确 task_id 或上个聊天摘要塞入提示词。

---

请先通过本项目的只读 Shared State 工具恢复上下文。
找到当前“雨天备选页面”任务，报告稳定任务 ID、负责人、当前状态、checkpoint、下一步和最后更新时间。
请说明状态是否可能过期，分别列出已记录的决定、证据及仍未提供的信息。
说明哪些信息不能证明已获得批准、已通过验证或可以发布。不要执行任何写入，也不要从聊天历史猜答案。
如果状态不可用，请明确说明，不要编造。

---

这份提示词不包含答案。验收员另行使用评分表核对工具结果。
