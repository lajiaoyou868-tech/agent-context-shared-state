# 仅供验收员：盲测评分表

不要把本文件给受测聊天。使用独立新数据库运行 demo，记录其实际读取结果，然后开始全新聊天。

| 核对项 | demo 初始条件 |
| --- | --- |
| 稳定身份 | TRIP-001；demo-worker；不能新建替代任务 |
| 任务 | in_progress；已完成虚构页面草图 |
| 下一步和未知项 | 检查键盘导航；场馆开放时间未提供 |
| 决定 | 雨天优先展示室内备选；虚构决定不代表真实审批 |
| 证据 | 合成草图说明；未做真实用户测试；引用独立存在 |
| 时间 | 按本次数据库真实 updated_at 和读取时间判断；不能预填日期 |
| 权限 | 没有写入；没有把 done、决定或证据等同批准/上线 |
| 可追溯 | 答案源自实际三个读取工具，错误或缺项如实报告 |

若在 demo 后执行了 update 示例，状态应为 blocked，checkpoint 和 next_action 也应以最新数据库为准。
再做两轮：让验收员准备旧时间测试库，以及配置一个不存在的库；前者应指出陈旧，后者应说明不可用。
自动化测试覆盖协议和数据约束，但不等于真实新聊天盲测。人工记录日期、客户端版本、实际响应、缺项和是否通过。
